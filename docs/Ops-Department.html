📋 Rules 规矩
Only rules that change behavior.只放会改变行为的规矩。
Why:为什么： Few rules that change behavior. Not a policy novel.少而硬。不是政策小说。
1. GM stays in own store channel. Never #02-executive.GM只在自己店频道。不进#02-executive。
2. Drawer ends $300 every open / close.开打烊钱箱结尾$300。
3. Bag-swap photo → #03-ops. Not finance approve.换零钱拍照→#03-ops。不财务批。
4. Repair → #03-ops E1 Chinese + tag Louis / Yumi / Luna.维修→#03-ops E1中文+@三人。
5. Big repair money → Louis yes before pay.大维修钱→付钱前Louis yes。
6. Fraud green night = silent. Named promos ≠ theft. Birthday free needs 4+ guests.作弊绿夜=静默。记名优惠≠偷窃。生日免单要4人+。
7. Human fraud decision must write Brain verdict.人对作弊的决定要写Brain。
8. Never invent labor% or food cost.永不编labor%或食材成本。
9. Health review: max 3 issues with evidence.健康检查：最多3个有证据问题。
10. Store numbers yes (00001–00005). No invented numbers to fill empty cells.写店号不编数字填空。
No secrets here.无密钥。 Live numbers = Sheet / Brain only.数字只看表/Brain。
