📋 Rules 规矩
Only rules that change behavior.只放会改变行为的规矩。
Why:为什么： Few rules that change behavior. Not a brand novel.少而硬。不是品牌小说。
1. Hermes never auto-publishes. Human posts after approval.Hermes永不自动发布。人批后人发。
2. Offer / promo / public promise → Louis M1 before publish.优惠/活动/公开承诺 → 发布前Louis M1。
3. Content = 3 designs. GM/Mkt picks 1. Max 2 revisions.内容=3稿。GM/市场选1。最多改2次。
4. 1–2★ and critical review replies → Louis. Food/injury/legal = immediate P0.1–2星和严重评价 → Louis。食物/受伤/法律=立刻P0。
5. Never invent prices, dates, scarcity, awards, or testimonials.永不编价格、日期、稀缺、奖项、好评。
6. Start from approved offer path, not a random caption idea.从已批优惠路径开始，不从随机文案开始。
7. Platform-native copy. No one bland caption for all channels.平台原生文案。不要全渠道同一句干文案。
8. Ad spend / paid launch → Louis M4 before money leaves.广告花费/付费上线 → 钱出去前Louis M4。
9. Brain = record. Drive = original file. Slack = act. No duplicate task lists.Brain=记录。Drive=原件。Slack=行动。不重复任务表。
10. Store numbers yes (00001–00005). No frozen live counts in this file.写店号。本文件不写死实时数字。
No secrets here.无密钥。 Live numbers = Brain / Slack / platform only.数字只看Brain/Slack/平台。
Success:成功： ping for gate decisions, not "what is the process?"找你拍板，不是问流程。
