Rules 规矩
Only rules that change behavior.只放会改变行为的规矩。
1. Every day produces a real artifact — not a note, not a plan.每天产出真成果 — 不是笔记，不是计划。
2. Numbers from Brain / Chowbus / 7shifts only. No guesses in decisions.数字只来Brain/Chowbus/7shifts。决策不许猜。
3. One problem at a time. Biggest first.一次一个问题。最大的先。
4. Order is law: Money → Leaders → Systems → Multiply. Don’t skip.顺序是法律：钱→人→系统→复制。不许跳。
5. Write it down or it didn’t happen. Simple words only.写下来才算。只用简单话。
6. Test: If Louis disappears 30 days, does each store get better, worse, or same?Louis消失30天，每店变好、变坏、还是不变？
Auto: Brain pulls, digests, scorecards — Louis only hits G1–G4.Brain拉数、摘要、记分卡 — Louis只打G1–G4。
Never auto: fire · bank/wire · invent approval · open store without unit economics开除 · 转账 · 编造批准 · 单店经济没搞清就开店
