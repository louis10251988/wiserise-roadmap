📋 First Principles Scorecard

1. Earns Rent?
Does this skill directly serve revenue, hiring, or operations? Top 20 = yes. Everything else is support or debt.
2. Findable?
Can you find the right skill in under 10 seconds? Search + team filter + "say this" trigger = yes.
3. Honest?
Real usage data from .usage.json — not opinion. Skills are sorted by actual activity, not a locked guess.
4. Safe?
Right permission on the right door. Team-safe = store staff can use. Louis-only = owner only. Unset = fix now.
5. Lean?
No dead weight. 0-activity skills go to Debt tab. Archive if cold. Kill if useless. 80/20 or die.
🔥 80/20 Rule
Top 20 skills ≠ equal weight to 120+. The Earn Rent tab is your 80/20. The rest is drawer noise.

🔁 The Loop (how this stays honest)

1. Work in Slack
→
2. Skill auto-loads

3. Usage counted
→
4. Rebuild Dojo
→
5. See what earns rent

⚠️ Pitfalls

• Stale Dojo after hermes skills install without rebuild → always rebuild after install
• Slack blocklist paths (agents/foo) silently fail → use skill names only
• Parking cold skills in _archive/ → still loaded → use .archive/
• Putting full skills into Supabase → wrong layer → Brain = data, not skill files
• Restarting gateway from Slack bot session → blocked → use Mac Terminal.app
